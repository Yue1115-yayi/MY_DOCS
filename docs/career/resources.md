# 中文手册工程包处理流程

## 1. 获取工程包
- 从曹润泽处获取工程包SVN地址
- 工程包包含：头文件（接口、结构体、枚举等）和典型应用文件

## 2. 待翻译注释提取
**背景**：V1.4项目对中文手册框架进行了大调整，英文手册仅完成头文件更新

### 操作步骤：
1. 将注释提取exe程序与头文件放置在同一路径下（支持批量操作）
2. 双击运行exe程序
3. 输入头文件所在路径（如：`D:\OTAPSDK\`）后按回车
4. 输入待生成的Excel文件名（如：`20230731-OTAPSDK待翻译注释`）后按回车
5. 打开生成的Excel文件检查注释提取情况
6. **重要**：点击保存按钮（避免Trados导入问题）

## 3. 翻译处理（Trados）
- 翻译记忆库位置：
  - 主要：集成资料开发
  - 备选：个人文件翻译记忆库（以时间最新的为准）
- 导出译文后检查并保存文件
- 将译文文件放回头文件所在路径

## 4. 译文回填
1. 将译文回填exe程序与头文件放置在同一路径下
2. 双击运行exe程序
3. 输入头文件路径后按回车
4. 输入已翻译的Excel文件名（如：`20230731-OTAPSDK待翻译注释_translated`）后按回车
5. 检查回填后的头文件内容准确性

## 5. Doxygen文档发布
### 发布前检查：
- 检查头文件和典型应用文件中未翻译内容
- 参考文档：《工具没有识别的内容》
  - 【V1.4头文件没有识别的内容】
  - 【V1.3典型应用没有识别的内容】
- 英文手册发布时需进行语言替换（详见checklist）

### 发布步骤：
1. Doxygen > File > Open → 选择`HCOTAPSDKConfig-ZH`配置文件
2. 图片处理：
   - 新增图片放入工程包pic文件夹
   - Doxygen > Expert > Input > IMAGE_PATH 添加图片路径
3. Run > Run Doxygen 生成chm文档

## 6. 项目复盘
- 汇总研发注释不规范导致的提取问题，反馈给曹工
- 大量未提取且有共性问题，向钱工提交脚本修改需求

## 注意事项
- 文档框架调整需修改`DoxygenLayout.xml`文件
- 典型应用中文手册已大幅调整，复用性需评估
